# Amazon Sales Intelligence Dashboard

## Overview

An Excel-based Sales Intelligence Dashboard developed to analyze 100 Amazon sales transactions across regions, product categories, customers, payment methods, and delivery statuses.

The project demonstrates how Excel can be used to transform raw transactional data into an interactive business reporting solution using data cleaning, XLOOKUP, Pivot Tables, calculated fields, KPIs, slicers, and charts.

## Objective

The objective was to build a dynamic sales dashboard that helps analyze:

- Revenue performance
- Regional sales
- Product category performance
- Delivery performance
- Order cancellations
- Customer information
- Monthly sales trends

## Tools & Techniques

- Microsoft Excel
- Pivot Tables
- XLOOKUP
- IF / IFERROR
- SUM / COUNT / AVERAGE
- Conditional Formatting
- Slicers
- Pivot Charts
- Date grouping
- KPI Cards
- Calculated Fields

## Data Analysis

The analysis includes:

1. Total sales by Region and Product Category
2. Order count by Delivery Status
3. Average Delivery Time
4. Cancellation Rate by Region
5. Effective Sales for Delivered Orders
6. Fast vs Slow Delivery Performance
7. Monthly Order Value
8. Top Performing Regions
9. Highest-selling Products

## Key Insights

- Total Revenue: $35,258
- Electronics generated the highest category revenue at $15,209.
- North recorded the highest cancellation rate at 40%.
- 11 orders were classified as Fast deliveries.
- Overall Fast Delivery rate was approximately 32.35%.
- South had the highest Fast Delivery rate among the regions at 50%.
- Leg Set and T-Shirt were tied for highest order count with 8 orders each.

## Dashboard Features

The dashboard provides an interactive view of sales and operational performance using:

- Region filters
- Payment Method filters
- Delivery Status filters
- Monthly sales analysis
- KPI cards
- Pivot Charts
- Conditional formatting

## Business Recommendations

Based on the analysis:

- Improve logistics and warehouse distribution in regions with weaker delivery performance.
- Consider pre-stocking high-demand electronics across regional warehouses.
- Review delivery-partner performance and evaluate alternatives where delivery times are consistently higher.
